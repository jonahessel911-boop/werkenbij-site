# Werken bij Batterijconcept

Vacature-site voor Batterijconcept — live op **werkenbij.batterijconcept.nl**.

Missie: de grootste verduurzamingsinstallateur van Nederland worden.

De consumentenwebsite staat apart op [batterijconcept.nl](https://www.batterijconcept.nl/).

## Lokaal

```bash
npm install
npm run dev
```

## Pagina’s

- `/` — home / werken bij
- `/vacatures` — open vacatures + solliciteren
- `/over-ons` — over Batterijconcept & ambitie
- `/contact` — adres en contact
- `/sales-vacature` — ZZP sales check
- `/appointment-vacature` — appointment setter check
